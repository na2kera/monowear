# 夜間に自分で判断したことの記録

グリルで確定した仕様から外れない範囲で、私（Claude）が判断した点を時系列で残しています。どれもあとから戻せます。

| # | 判断した内容 | 理由 | 戻し方 |
|---|---|---|---|
| 1 | 色数を「3色の商品が6点、2色の商品が16点」とし、合計50色 × 3カット ＝ 150枚にした | 全商品を2〜3色にすると枚数が150前後から大きく外れるため | `src/data/products.ts` の colors を編集 |
| 2 | 生成した PNG（1枚1〜2MB）はそのまま使わず、`sips` で長辺1200pxの JPEG（約80KB）に変換して `public/images` に置いた。元の PNG は `.raw-images/`（git 管理外）に残している | PNG のままだと合計約250MBになり、リポジトリが重くなるうえ一覧画面の表示も遅くなる。遅さは意図した「悪さ」ではないため | `scripts/generate-images.ts` の `convert()` |
| 3 | サンプルの5枚のうち4枚（白Tの正面・背面、ネイビーのニット正面、白スニーカー）を本番に流用した。白Tのディテールは余白が大きかったので、寄りを強めて作り直す | 承認済みのテイストを基準画像にすると、量産分の統一感を保ちやすい | `.raw-images/` の該当ファイルを消して再生成 |
| 4 | 在庫切れは「t03 グリーン全サイズ」「b02 全色全サイズ」「o01 全色全サイズ」「s01 ホワイト 26.5・27.0」の4点にした | #6（在庫切れが詳細を開くまで分からない）を、全部在庫切れの商品と一部だけ在庫切れの商品の両方で体験できるようにするため | `products.ts` の soldOut |
| 5 | フッターと購入手続き画面に「ワークショップ用の架空のサイトで、実際の決済は行われない。実在のカード番号や個人情報は入力しないでください」という注記を入れた | 参加者が本物のカード番号などを入力してしまうのを防ぐため。没入感より安全を優先した | `Footer.tsx` / `Checkout.tsx` の注記 |
| 6 | デプロイ先を Cloudflare Pages ではなく **Workers の静的アセット配信**にした。URL は https://monowear.na2kera.workers.dev | wrangler 4.163 では `pages project create` が Workers に統合されていて、Pages のプロジェクトを作れなかったため。robot-gacha-battle と同じ方式で、静的ファイルだけを配信する設定（`wrangler.jsonc`）にしている | `wrangler.jsonc` を削除し、Pages を使う形に戻す |
| 7 | `wrangler` を devDependencies に追加し、`npm run deploy`（ビルドしてからデプロイ）と `npm run images`（画像生成）のスクリプトを用意した | 夜間に何度もデプロイするため、手順を固定したかった | `package.json` の scripts |
| 8 | noindex は `<meta name="robots">`、`X-Robots-Tag` ヘッダー（`public/_headers`）、`robots.txt` の3つで指定した | 検索エンジンにインデックスされないようにするため | `public/_headers`、`public/robots.txt`、`index.html` |
| 9 | 購入手続き画面では、各欄の下に「全角で」「半角で」といった注記を表示している（#18）。エラーは「全角で入力してください。」のように欄名を出さず、重複をまとめて表示する（#19） | 「指定はあるのに、どれが原因か分からない」状態を作るため | `Checkout.tsx` |
| 10 | 会員登録画面のエラー時は、ページの先頭までスクロールしてエラー一覧を見せる。そのうえでフォームを作り直し、入力内容を全部消す（#16） | 「エラーが出たことには気づくが、入力したものが全部消えている」という体験にするため | `Register.tsx` の formKey |
| 11 | Fable と Codex のレビューを受けて、意図しない不具合を直した：数量が11以上になるとカートの表示が壊れる／b02 の在庫切れ設定漏れ（判断 #4 と食い違っていた）／カルーセルのドットを押すとページが移動する／会員登録済みでもカートから毎回会員登録画面へ飛ぶ／会員登録でメール形式をチェックしていない／カラーで絞り込んでも1色目の画像が出る／番地の半角スペースで全角エラーになる | 20個以外の不具合が議論の邪魔をしたり、購入完了まで進めなくなったりするのを防ぐため | 各コミットを参照 |
| 12 | ヘッダーの「税込11,000円以上で送料無料」の告知を「WINTER COLLECTION 新作アイテム入荷中」に変え、送料無料の条件を 15,000円以上に引き上げた | 告知があると #14（送料が最後まで分からない）が効かず、2〜3点入れるだけで送料無料になって送料が出てこなくなるため | `Header.tsx`、`cart.ts` の `FREE_SHIPPING_THRESHOLD` |
| 13 | ヘッダーの「ログイン」を「会員登録」に変え、登録済みなら「〇〇 様」と表示するようにした | ログイン画面がないのに「ログイン」から登録フォームに飛ぶと、21個目の悪さとして議論が取られるため | `Header.tsx` |
| 14 | クーポンは「次回以降のご注文で使える」という文言にし、登録すると約2秒でモーダルが閉じるようにした | このサイトにはクーポンを使う場所がないため、参加者が探し回らないようにした | `CouponModal.tsx` |
| 15 | 講師用に `/reset`（localStorage を消してトップに戻る）を追加した | リハーサル後や端末の使い回しで、最初の状態に戻す手段がなかったため | `src/pages/Reset.tsx` |
| 16 | 在庫切れのカラーを選んでも「残り2点！」は出したままにした | 「在庫切れなのに残り2点」という矛盾が、#10 が嘘だと気づくきっかけになるため | `ProductDetail.tsx` |
